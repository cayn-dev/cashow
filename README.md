# Cashow

📱 Descrizione super-dettagliata dell’app

L’app deve essere un gestionale finanziario personale progettato per aiutare l’utente a monitorare in modo semplice ma professionale entrate, uscite, risparmi e stipendio.
L’interfaccia deve essere moderna, elegante, completamente nera con effetto liquid-glass (pannelli traslucidi, riflessi morbidi, ombre leggere e bordi arrotondati).

🎯 Obiettivo principale

Permettere all’utente di avere sempre sotto controllo i suoi soldi, capire dove vanno le spese, come cresce lo stipendio, e quanto sta risparmiando ogni mese.

🧾 Funzioni principali (molto dettagliate)
1️⃣ Registrazione ENTRATE e USCITE

Ogni movimento deve avere:

Data

Ora

Importo

Categoria (es: cibo, abbigliamento, scuola, divertimento, bollette, ecc.)

Descrizione libera

Metodo di pagamento (contanti, carta, PayPal, ecc.)

Possibilità di aggiungere un’icona o emoji alla categoria

Possibilità di allegare foto (scontrino, fattura, ecc.)

Possibilità di segnare se è:

spesa singola

spesa ricorrente (mensile, settimanale, annuale)

2️⃣ Sezione STIPENDIO

Due campi separati:

💰 Stipendio effettivo mensile

Lo stipendio reale ricevuto ogni mese (può essere modificabile).

➕ Stipendio cumulativo

Uno storico che:

parte da 0

aumenta ogni volta che arriva uno stipendio o un’entrata marcata come “stipendio”

mostra come cresce nel tempo

Grafico consigliato: linea o barra, con progressione mensile.

3️⃣ Sezione RISPARMI

Sistema dedicato per tenere traccia dei soldi messi da parte:

saldo attuale risparmi

obiettivi (es: “nuovo telefono”, “vacanze”, “pc nuovo”)

importo obiettivo + percentuale raggiunta

barra di avanzamento animata

timeline dei depositi e prelievi dal salvadanaio

Notifica:

“Complimenti! Hai raggiunto il 50% del tuo obiettivo 🎯”

4️⃣ DASHBOARD PRINCIPALE

La schermata iniziale deve essere chiara e visiva:

Totale entrate mese corrente

Totale uscite mese corrente

Saldo del mese

Stipendio ricevuto

Risparmio totale

Grafici circolari delle spese per categoria

Grafico a linea per l’andamento mensile

Tutto con animazioni fluide.

5️⃣ FILTRI & RICERCA AVANZATA

L’utente deve poter filtrare:

per data (giorno, settimana, mese, anno)

per categoria

per importo minimo/massimo

per metodo di pagamento

solo ricorrenti / solo una tantum

Ricerca rapida per parola chiave.

6️⃣ NOTIFICHE SMART

Non troppe, ma utili:

ricordarti di registrare spese giornaliere

avviso quando spendi troppo rispetto alla media

reminder per entrate o spese ricorrenti

notifica obiettivi risparmi raggiunti

7️⃣ BACKUP & PRIVACY

Backup su cloud (Google Drive, iCloud, ecc.)

Pin / Face ID / impronta digitale

Dati criptati

Nessuna pubblicità invasiva

🎨 Stile grafico (importantissimo)

Tema generale: nero + liquid glass.

Caratteristiche estetiche:

sfondi neri profondi

pannelli traslucidi grigio-vetro

bordi arrotondati

ombre soffici

icone minimal

grafici con effetto luminoso soft

animazioni fluide (aperture, transizioni, micro-movimenti)

Deve sembrare un’app premium, elegante, futuristica ma semplice.

🧠 Extra intelligenti (facoltativi ma consigliati)

Suggerimenti automatici: “stai spendendo troppo in X”

Previsioni spese del mese

Possibilità di esportare in PDF/Excel

Modalità “studente” o “lavoratore”

Widget nella home del telefono

Modalità chiara (opzionale — default scura)
